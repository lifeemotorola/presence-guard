MixBloom user guide

A practical guide to your OBS audio mixer. Created by Emmanuel Suah. Available offline. Select a section below or scroll to read; use Tab and Enter to follow links with a keyboard. In OBS, press Esc or select Close when you are finished.

Live audio: Level, mute, track and monitoring changes take effect in OBS immediately, even during a stream or recording. Opening the guide does not change your audio. Test your setup with a private recording first.

In this guide: Quick start · Audio sources · Level & mute · Output tracks · Monitoring · Source meter · Troubleshooting · Install & update · Privacy & limits

01 / Quick start

  1. In OBS, set up a microphone, desktop audio or another audio source. Open Docks → MixBloom.
  2. Find the source in the dock. Use Level and Mute to adjust the actual OBS source. Changes also appear in OBS's mixer.
  3. Select the source's output track buttons. In OBS Settings → Output, choose the matching streaming or recording track where available.
  4. Make a private test recording and listen back. Adjust before going live.

MixBloom uses existing OBS sources. It does not require iRig hardware or a special driver, but a physical microphone or instrument still needs a working input or interface recognized by OBS.

02 / Find or add audio sources

Set up a global microphone or desktop device under OBS Settings → Audio, or add an audio source to a scene from the OBS Sources list. Follow OBS's device-selection steps and make sure the device works in Windows.

MixBloom lists public audio-capable sources in the current scene collection. A listed source may not be active in the current scene. The list updates automatically; Refresh checks immediately. Sources with similar names remain separate.

If the list is empty, add or enable an OBS audio source and check that the intended scene collection is open. MixBloom cannot create or select a physical input for you.

03 / Level and mute

  • Level changes the source's OBS volume. The slider runs from silence to 0 dB; it cannot boost above 0 dB.
  • Mute / Unmute affects that source on all of its OBS tracks. The source's settings apply across scenes that use it.
  • If a source is already boosted above 0 dB in OBS, the actual value is displayed and remains unchanged until you move the MixBloom slider; moving it caps the level at 0 dB.
  • If the level is locked in the OBS mixer, unlock it there before changing it here. Mute and routing are separate controls.

There is no undo or solo. Uninstalling MixBloom does not restore earlier OBS audio settings.

04 / Route to output tracks

The numbered buttons 1–6 are the OBS audio tracks for that source. Highlighted buttons are selected. Click a number to add or remove that source from a track. Removing the final selected track requires confirmation; no tracks selected can leave the source out of the output.

Track selection applies to the source across scenes, not only to the currently visible scene. In OBS Settings → Output, check that the stream or recording uses a track containing the sources you want. Options vary with OBS's output mode and recording format.

Example: for a simple test, put your microphone and desktop audio on track 1, select the corresponding output track in OBS, then record and listen back. A selected track button or moving meter alone does not prove that your audience can hear it.

05 / Listen with monitoring

Monitor: Off / On controls whether OBS also sends the source to its configured monitoring device. MixBloom asks before turning monitoring on. Check the monitoring device in OBS Settings → Audio.

Avoid feedback: use headphones and make sure desktop capture does not recapture your monitoring device. Speakers, microphones and desktop capture can form a feedback loop. Turn monitoring off immediately if you hear feedback.

OBS marks some sources, commonly desktop output capture, as unsafe to monitor. MixBloom will not enable monitoring for those sources, but can turn existing monitoring off. Monitoring here is in addition to selected output tracks; this dock does not offer monitoring-only routing.

06 / Read the source meter

The Source peak bar shows the highest channel reported by the OBS source meter after the fader. The scale runs from −60 to 0 dB. It can move even when the source is muted.

The source meter does not measure the final stream or recording, loudness, or true peak. A still meter can mean the source is inactive or not sending audio; it is not a diagnosis. Listen to the final recording or stream separately.

07 / Troubleshooting

No sources appear

Add an audio source in OBS, choose the correct scene collection and use Refresh. Some listed sources may be inactive in the current scene.

No sound in a recording or stream

Check the device in Windows and OBS, make sure the source is active and unmuted, check its level and filters, and select a matching source and output track. Record a short private test and listen back.

Feedback or echo

Turn monitoring off, use headphones, and check that your speakers or desktop capture are not feeding monitored sound back into OBS.

The dock is missing

Restart OBS and open Docks → MixBloom. Check Help → Log Files → View Current Log for [obs-mixbloom] loaded. Confirm that the DLL and data were installed together. This build targets OBS 33.0.1 on Windows x64.

08 / Install, update or remove

Download obs-mixbloom-windows-x64 from a successful Actions → MixBloom run for main on the project's GitHub page. Extract the ZIP and close OBS. Right-click Install.bat and choose Run as administrator, then reopen OBS and select Docks → MixBloom.

To update a standard installation, close OBS and back up any files you want to keep from the old obs-mixbloom plugin folder. Run the new package's Uninstall.bat as administrator, then run Install.bat as administrator. The installer will not overwrite an existing folder. Removing the plugin does not undo audio changes already made in OBS.

For portable OBS, use the package's PowerShell install and uninstall scripts with -PluginRoot pointing to that portable copy's plugins folder. See the included README for an example. The DLL and installer are unsigned. A separate copy of this guide is included at data/help/user-guide.html.

09 / Privacy and limits

MixBloom has no account and does not intentionally send audio, source names or analytics over the network. Its source meter uses values supplied by OBS; the plugin does not save or record audio. OBS manages the source settings you change.

This dock is not an official iRig product. It does not provide effects, a virtual cable, a separate mix bus, presets, automatic mixing or a new physical input. It cannot guarantee what listeners hear; always verify the final output.
